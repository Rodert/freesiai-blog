## 欢迎来到自由域

这是自由域的第一篇公开测试文章，用于检查站点发布流程和阅读体验，不是工具使用教程。

自由域将分享 AI 工具与实用图文指南；有视频演示的文章也会提供文字步骤，便于查阅。

## 测试文章地址

本篇文章的固定地址是 [https://freesiai.com/1.html](https://freesiai.com/1.html)。文章标题或分类改变后，这个地址仍会保留。

可以刷新页面，或直接将地址复制到新的浏览器窗口，检查文章是否正常显示。若地址发生跳转，也可以在评论中反馈跳转后的地址。

## 测试全文搜索

打开 [站内搜索](/search/)，分别尝试以下关键词：

- 标题关键词：`站点功能测试`
- 正文关键词：`星河测试`

这里的“星河测试”是专门用于验证正文检索的测试词。搜索结果应能找到这篇文章，并链接到 `/1.html`。

## 检查图文排版

下面的代码块仅用于测试显示效果，无需执行：

```javascript
const siteName = '自由域';
console.log(`${siteName}：第一篇文章排版测试`);
```

| 检查项目 | 测试方法 |
| --- | --- |
| 手机阅读 | 检查标题、正文和表格是否可读，页面是否出现横向溢出 |
| 分类导航 | 点击“实用指南”，检查能否找到本篇文章 |
| 全文搜索 | 查询标题关键词和正文测试词 |
| 评论入口 | 查看文章底部是否显示 Giscus 评论框 |

> 本文没有关联 YouTube 视频，因此不应显示视频播放器。

## 测试评论

文章底部使用 Giscus 评论，留言需要登录 GitHub。如果评论区已正常加载，可以留下一条“自由域评论测试”，验证评论是否能发送和显示。

如果评论区无法加载，请先确认当前网络可以访问 GitHub 和 Giscus。正文阅读不依赖评论服务。

感谢参与测试。后续正式教程发布后，会继续沿用这个站点的文章、分类和搜索入口。
